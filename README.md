# soil-moisture-arduino
Monitoring of Soil Moisture and Water Pump Control Using Arduino
💡 Introduction of Project

This is a simple yet practical project where an Arduino can be used for automatic plant watering. The moisture content in the soil is monitored and water pumps are controlled accordingly.

With this project, you do not have to manually check and water the plants anymore. This project helps in saving both time and water.

⚙️ Components Needed
Arduino Uno Board
Soil Moisture Sensor
Relay Module
Water Pump
Jumper Wires
🔄 Operation of Project

The soil moisture sensor is installed in the soil and the moisture content is measured.

Once the soil gets dried, the soil moisture sensor senses it and gives the signal to the Arduino Board.
Arduino activates the relay module which activates the water pump.
As soon as sufficient moisture is found in the soil, Arduino deactivates the relay and switches off the water pump.
